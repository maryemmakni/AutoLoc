# AutoLoc

Plateforme de gestion de location de véhicules multi-agences.

## Objectifs du projet
- Gérer les véhicules, les clients et les locations de plusieurs agences.
- Suivre les contrats, les paiements et la maintenance des équipements.

## Acteurs
- **Client** : consulte les véhicules et réserve.
- **Agent d'agence** : enregistre les locations et les retours.
- **Responsable d'agence** : supervise son agence.
- **Administrateur** : gère les agences et les utilisateurs.

## Cas d'utilisation (v0)
- Rechercher un véhicule disponible
- Réserver un véhicule
- Enregistrer un paiement
- Gérer les agences

## Stack technique
Java 17, Spring Boot, Spring Data JPA, Maven, MySQL, Lombok, Postman, Git.
